StockControl

Sistema de control de inventario para pequenas y medianas empresas. Una plataforma web para administrar y una aplicacion movil para trabajar en la bodega, conectadas a la misma informacion.

Plataforma web

Para administradores y supervisores. Pensada para pantallas grandes, con tablas, filtros e indicadores.

  • Panel con indicadores y grafico semanal
  • Administracion de articulos y categorias
  • Historial de movimientos y alertas de stock
  • Gestion de usuarios y sus permisos

Aplicacion movil

Para el personal de bodega. Pensada para usarse de pie, con una mano y en movimiento.

Como se integran los dos canales

La web y el movil no son dos sistemas separados: son dos formas de entrar al mismo sistema. Ambos se comunican con una API REST que trabaja sobre una unica base de datos, asi que la informacion siempre coincide.

Aplicacion movil El operario escanea y registra el movimiento en la bodega
API REST + base de datos Valida el usuario, los permisos y el stock. Guarda la operacion una sola vez
Plataforma web El supervisor ve el movimiento reflejado al instante en sus paneles
1
EscaneoEl operario lee el codigo del articulo con la camara del telefono.
2
ValidacionLa API comprueba identidad, permisos y stock antes de guardar.
3
RegistroEl movimiento se guarda con usuario, fecha, ubicacion y origen.
4
ConsultaEl dato aparece en los indicadores y reportes de la web.
Una sola base de datosEl stock nunca queda distinto entre lo que ve el operario y lo que revisa el supervisor.
Las mismas cuentasUn usuario sirve para los dos canales; lo que cambia son los permisos segun el rol.
Origen identificadoCada movimiento indica si se registro desde el movil o desde la web, para mantener la trazabilidad.
