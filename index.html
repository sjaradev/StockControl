StockControl

Sistema de control de inventario para pequeñas y medianas empresas. Una plataforma web para administrar y una aplicación móvil para trabajar en la bodega, conectadas a la misma información.

Plataforma web

Para administradores y supervisores. Pensada para pantallas grandes, con tablas, filtros e indicadores.

  • Panel con indicadores y gráfico semanal
  • Administración de artículos y categorías
  • Historial de movimientos y alertas de stock
  • Gestión de usuarios y sus permisos

Aplicación móvil

Construida con Ionic, el mismo código funciona en iOS y en Android. Se puede instalar en el teléfono desde el navegador.

  • Escaneo de códigos de barra y QR
  • Registro de entradas, salidas y traslados
  • Consulta de stock y ubicación en terreno
  • Interfaz iOS o Android con un toque

Cómo se integran los dos canales

La web y el móvil no son dos sistemas separados: son dos formas de entrar al mismo sistema. Ambos se comunican con una API REST que trabaja sobre una única base de datos, así que la información siempre coincide.

Aplicación móvil El operario escanea y registra el movimiento en la bodega
API REST + base de datos Valida el usuario, los permisos y el stock. Guarda la operación una sola vez
Plataforma web El supervisor ve el movimiento reflejado al instante en sus paneles
1
EscaneoEl operario lee el código del artículo con la cámara del teléfono.
2
ValidaciónLa API comprueba identidad, permisos y stock antes de guardar.
3
RegistroEl movimiento se guarda con usuario, fecha, ubicación y origen.
4
ConsultaEl dato aparece en los indicadores y reportes de la web.
Una sola base de datosEl stock nunca queda distinto entre lo que ve el operario y lo que revisa el supervisor.
Las mismas cuentasUn usuario sirve para los dos canales; lo que cambia son los permisos según el rol.
Origen identificadoCada movimiento indica si se registró desde el móvil o desde la web, para mantener la trazabilidad.

La versión anterior del prototipo móvil, hecha a mano sin framework, sigue disponible en movil.html como referencia del diseño inicial.
